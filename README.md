# Учёт путевых листов

Внутренняя система учёта служебного транспорта: путевые листы, автомобили, водители, техническое обслуживание и отчёты.

## Технологии

- Go
- html/template
- SQLite
- modernc.org/sqlite

## Возможности

- Учёт путевых листов
- Контроль разрывов пробега
- Контроль расхода топлива
- Учёт автомобилей
- Учёт водителей
- Журнал технического обслуживания
- Напоминания о приближающемся ТО
- Отчёты по автомобилям и водителям
- Дашборд с важными показателями
- Пагинация и сортировка списков
- Экспорт путевых листов и отчётов в CSV
- Серверная валидация форм
- Логирование запросов
- Восстановление после паники
- Базовые заголовки безопасности
